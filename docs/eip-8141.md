Frames uses a local decoded JSON fixture based on the frame fields and modes defined at https://eips.ethereum.org/EIPS/eip-8141 . Admission checks frame shape, chain and a per-sender sequence number. Results reference each frame index. This policy models nonce admission only. Cryptographic verification and execution of APPROVE are outside the local model.

The editor accepts a decoded fixture or a JSON object containing a raw type-06 transaction. Each admission evidence record exports a standalone regression test. Download it and run node frame-replay.mjs.

To enable manual devnet submission, configure CHAINXRAY_DEVNET_RPC and CHAINXRAY_DEVNET_CHAIN before launch. Choose a dedicated development chain. Supply an externally prepared signed frame and type SUBMIT followed by the displayed chain ID. The adapter checks eth_chainId before sending and records the endpoint response. A transport error leaves admission unknown. Local fixture admission remains available when the endpoint is down.
